# DA Block Library Content

These files are source templates for Document Authoring's Library > Blocks panel.

DA does not populate the Library > Blocks list from `component-definition.json`.
To show the Forms block there, create the matching DA content:

- `/blocks/forms` document using `da-library/blocks/forms.html` as the block sample.
- `/library/blocks` sheet using `da-library/library/blocks.csv` as the row source.

After creating those DA documents, preview/publish the library documents in DA and reopen the editor.
